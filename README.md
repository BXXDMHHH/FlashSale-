# FlashSale

FlashSale 秒杀商城项目，目标技术路线：

- Android 用户端：Kotlin + Jetpack Compose
- 后端：Java + Spring Boot
- 管理端：Vue 3 + TypeScript
- 架构：DDD 思路下的模块化单体，REST API，关系型数据库

## 开发文档

- [生产开发设计文档（V1.0 设计基线）](docs/PRODUCTION_DEVELOPMENT_PLAN.md)

文档包含项目范围、系统架构、业务规则、DDD 聚合边界、数据库设计建议、REST API 草案、事务与并发策略、权限安全、测试验收和开发里程碑。

仓库当前提交的是设计文档，不代表 Android、Spring Boot 或 Vue 功能代码已经实现。开发前需要根据文档第 16 节确认未决技术和业务决策，再按开发阶段逐步实现和测试。
